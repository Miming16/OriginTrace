# 0.1.3 — Non-Functional & Integration Requirements

## Runtime requirements

- PostgreSQL 14 or newer stores application data.
- The API listens on port 8000 and the Vite frontend listens on port 5173.
- `DATABASE_URL`, `JWT_SECRET`, and `FRONTEND_ORIGIN` are supplied through environment variables.
- JWTs are held in frontend memory only; they are not persisted in browser storage.

## Security requirements

- Passwords are compared against bcrypt hashes and are never returned by the API.
- Protected endpoints require a valid Bearer token.
- Role middleware returns 403 when a valid user token has the wrong role.
- CORS allows only the configured frontend origin.

## Integration requirements

- The frontend uses `VITE_API_BASE_URL` to reach the API.
- The API uses the initial PostgreSQL migration mounted by Docker Compose.
- Health checks must be available at `GET /api/health`.
- Route access behavior is covered by backend integration tests.
